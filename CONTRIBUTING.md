# Contributing to TROA projects

Thank you for helping improve The Realms of Asgard's public tools and documentation.

## Before opening work

1. Read the target repository's README, license, and local contribution guidance.
2. Search existing issues and pull requests to avoid duplicating work.
3. Open an issue before substantial changes unless a maintainer has already approved the direction.
4. Never include credentials, private server details, player information, production data, or private TROA source.

## Pull requests

- Keep each pull request focused on one concern.
- Explain the problem, the approach, user-visible effects, risk, and verification performed.
- Include screenshots or logs when they materially help reviewers.
- Update documentation and examples when behavior changes.
- Preserve compatibility and recovery paths for server-facing releases.

Public repositories may be release-and-documentation repositories rather than open-source projects. A public repository does not grant permission to redistribute, reverse engineer, or modify proprietary software; consult that repository's license.
