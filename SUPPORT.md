# Support

## Product support

Use the affected public repository's issue tracker for reproducible bugs and documentation problems. Include the product version, environment, expected result, actual result, and safe reproduction steps.

## Community and account support

Use the support channels linked from [therealmsofasgard.com](https://therealmsofasgard.com) or the official [TROA Discord](https://discord.gg/troainc).

## Security and privacy

Never post credentials, player information, private server details, production data, or vulnerability details in a public issue. Follow [`SECURITY.md`](SECURITY.md).
