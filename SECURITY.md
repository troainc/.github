# Security policy

## Reporting a vulnerability

Do not disclose security vulnerabilities, credentials, private server details, player information, or production data in a public issue.

Report security concerns privately through the security-reporting option on the affected repository when available. If repository-private reporting is unavailable, contact TROA through the official website or Discord and request a private security contact channel. Include only the minimum information needed to establish contact until a private channel is confirmed.

Please include:

- The affected repository, component, and version
- A clear description of the impact
- Reproduction steps or a minimal proof of concept
- Any known mitigations

TROA will acknowledge actionable reports, evaluate severity, and coordinate remediation and disclosure where appropriate.
